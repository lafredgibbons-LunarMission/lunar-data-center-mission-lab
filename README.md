# Lunar Data Center Mission Lab

An interactive educational simulator for exploring the power, energy-storage, and heat-rejection tradeoffs of a conceptual lunar data center.

## Run locally

Open `index.html` in a browser. No installation or build step is required.

## Deploy with Vercel

1. Upload `index.html` and this README to the root of a GitHub repository.
2. Import the repository into Vercel.
3. Keep the framework preset as **Other** and deploy with the default settings.

## Model scope

The model simulates 708 hourly steps (29.5 Earth days) using simplified site illumination, electrical generation, battery storage, facility overhead, and heat-rejection limits. It is an educational systems model, not a mission-planning tool.
